When does a coordinate become a feature?

A neuron has a number attached to it on every forward pass. That number alone does not tell us what the model represents or how it computes. Start with the distinction between an abstract vector, the coordinates used to record it, and a downstream operation that reads those coordinates. This distinction underlies the Goodfire essays on native neurons, feature manifolds, and parameter decomposition.

Use column vectors throughout. A vector $x\in\mathbb{R}^d$ has $d$ real components. Its Euclidean inner product with $u\in\mathbb{R}^d$ is $u^Tx=\sum_{i=1}^d u_ix_i$, and its norm is $\|x\|_2=\sqrt{x^Tx}$. A direction $u$ is a unit vector when $u^Tu=1$. The scalar $u^Tx$ is the signed projection of $x$ onto that direction. An activation vector is the collection of values at a specified location in a network, for a specified input.

Matrices describe operations, not just storage

Let a hidden layer have width $m$ and the output have width $k$. The affine maps are

$$h=W_1x+b_1,\qquad y=W_2h+b_2,$$

where $W_1\in\mathbb{R}^{m\times d}$, $b_1\in\mathbb{R}^m$, $W_2\in\mathbb{R}^{k\times m}$, and $b_2\in\mathbb{R}^k$. Each row of $W_1$ defines a weighted combination of input coordinates. Each column of $W_2$ tells us how one hidden coordinate contributes to all outputs.

Two consecutive affine layers collapse to one. If no nonlinearity or input-dependent operation intervenes, then $y=(W_2W_1)x+(W_2b_1+b_2)$.

Substitute the first equation into the second and distribute matrix multiplication. The matrix $W_2W_1$ has shape $k\times d$, and its rank is at most $\min(k,m,d)$ because its image lies inside the image of $W_2$. Extra affine depth alone therefore does not create a nonlinear function. A narrow intermediate layer can still impose a rank restriction.

The rectified linear unit, $\operatorname{ReLU}(z)=\max(0,z)$, applied componentwise breaks this collapse. Different coordinates turn on in different input regions. Within one fixed on/off pattern a ReLU network is affine, but different patterns generally have different affine maps.

A function can survive a change of hidden coordinates

At an interface where a vector $h$ is followed by a linear readout $y=Wh$, choose any invertible matrix $A$. Define $h'=Ah$ and $W'=WA^{-1}$. Then

$$W'h'=WA^{-1}Ah=Wh.$$

The output is unchanged even though individual coordinates can become harder to describe. This is an exact algebraic reparameterization of the specified interface. It does not imply that arbitrary rotations can be moved through every component of an existing network.

A nonlinearity makes the interface important. Put $x=(1,-1)^T$ and let $R$ be the $45$-degree rotation $2^{-1/2}\begin{pmatrix}1&-1\\1&1\end{pmatrix}$. Then $R\operatorname{ReLU}(x)=(2^{-1/2},2^{-1/2})^T$, whereas $\operatorname{ReLU}(Rx)=(\sqrt{2},0)^T$. The two vectors differ. A coordinate argument that silently commutes a rotation through ReLU has changed the computation.

This is a useful question to carry into Neural Networks Are Already Clean: which architectural operations make the native neuron basis special, and which observations would remain unchanged under an allowed reparameterization? Interpretability must specify both its representation and its computational interface.

Large variance is not the same as task relevance

For a centered random activation vector $h$, its covariance is $\Sigma=\mathbb{E}[hh^T]$. Principal component analysis, or PCA, selects unit directions maximizing variance. The variance along $u$ is $u^T\Sigma u$. Diagonalizing the symmetric covariance matrix gives eigenvectors ordered by their eigenvalues, which are those variances.

Consider independent, zero-mean, unit-variance scalars $z,t$ and activations $h=(10z,t)^T$. Their covariance is $\operatorname{diag}(100,1)$. The first principal component is the first coordinate. If the prediction target is $t$, that high-variance component is irrelevant to the target under the stated independence assumption. PCA answers a geometric question about variation; relevance to a task requires another measurement.

When eigenvalues are equal, the corresponding principal directions are not uniquely determined. A plot of the first two components is a projection, not a proof that the full representation has two intrinsic dimensions. The World Inside Neural Networks and its companion geometry papers make these distinctions operational.

Practice and a local check

Run the coordinate and PCA experiment after predicting its outcome. It checks output invariance under a hidden-interface rotation and constructs a task-relevant low-variance direction. The experiment illustrates the algebra here; it is not a replication of a Goodfire empirical result.

  1. Set $W_1=\begin{pmatrix}1&2\\0&1\end{pmatrix}$, $W_2=(3,-1)$, and both biases to zero. Compute the collapsed readout and its value at $x=(2,1)^T$.
  2. For $h=(10z,t)$ above, compute the fraction of total variance retained by the first PCA component. Does that fraction imply good prediction of $t$?
  3. A direction can predict a label while every individual coordinate looks mixed. Describe an interface-preserving experiment separating basis dependence from a change in the network's function.

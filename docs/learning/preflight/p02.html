Trace a small computation before interpreting a large one

Mechanistic work asks what an existing network computes internally. Training asks how its parameters changed to produce that network. These are related questions, but a gradient used during training is not automatically an explanation of a trained model's behavior. A small construction makes the distinction visible.

Let $x\in\mathbb{R}$ be a scalar input. Define two hidden activations $h_+=\max(0,x)$ and $h_-=\max(0,-x)$, and output $y=h_++h_-$. The parameters are fixed by construction. There is no training data in this example.

This network computes absolute value. For every real input, $y=|x|$.

If $x\geq0$, then $h_+=x$ and $h_-=0$, so $y=x$. If $x\lt0$, then $h_+=0$ and $h_-=-x$, so $y=-x$. These cases cover the real line and agree at zero.

Inspect the specified mechanism

Exact arithmetic for this constructed network; no model download or network request.

At $x=-3$, the activations are $(0,3)$ and the output is $3$. Clamping $h_-$ to zero changes the output to $0$, whereas clamping $h_+$ to zero leaves it at $3$. At a positive input their roles reverse. A component's causal importance depends on the input and the intervention.

Gradients are local statements

For $x\neq0$, $dy/dx$ is $1$ on the positive side and $-1$ on the negative side. The derivative at zero does not exist because the one-sided derivatives disagree. An automatic-differentiation system can adopt an implementation convention at the ReLU boundary; that chosen value is not a proof of differentiability.

For a general composition $h=\phi(Wx+b)$, $y=v^Th$, the chain rule gives

$$\nabla_xy=W^T\operatorname{diag}(\phi'(Wx+b))v,$$

where $x\in\mathbb{R}^d$, $W\in\mathbb{R}^{m\times d}$, $b,v\in\mathbb{R}^m$, and $\phi$ acts componentwise. The diagonal matrix records each scalar derivative. For ReLU away from its boundaries, each diagonal entry is zero or one.

The first-order approximation $f(x+\delta)\approx f(x)+\nabla f(x)^T\delta$ describes sufficiently small changes within a smooth region. A large ablation can cross multiple boundaries. Its effect must be computed by the modified forward pass, rather than inferred solely from a local gradient.

What gradient descent changes

Let $\theta$ collect trainable weights and biases and let $L(\theta)$ be a differentiable training loss. A gradient-descent step is $\theta_{t+1}=\theta_t-\eta\nabla_\theta L(\theta_t)$, with positive step size $\eta$. The first-order change in loss is approximately $-\eta\|\nabla L\|_2^2$. This is a local expansion, not a guarantee that any chosen step size lowers the actual loss.

For a classification problem with $k$ outputs, logits are unconstrained scores $z\in\mathbb{R}^k$. Softmax converts them to probabilities $p_i=e^{z_i}/\sum_j e^{z_j}$. For target class $c$, cross-entropy loss is $\ell=-\log p_c=-z_c+\log\sum_j e^{z_j}$. Differentiating gives $\partial\ell/\partial z_i=p_i-\mathbf{1}\{i=c\}$. The loss moves the target logit upward relative to competitors; the network's internal parameter changes depend on the rest of the chain rule.

The transformer forward pass in dimensions

A sequence of $n$ token representations is a matrix $X\in\mathbb{R}^{n\times d}$. A single attention head forms $Q=XW_Q$ and $K=XW_K$ in $\mathbb{R}^{n\times d_k}$ and $V=XW_V$ in $\mathbb{R}^{n\times d_v}$. Each row corresponds to one token position. Its output is

$$A=\operatorname{softmax}_{\mathrm{row}}\!\left(\frac{QK^T}{\sqrt{d_k}}+M\right),\qquad O=AV.$$

The rowwise softmax makes each row of $A$ sum to one. A causal mask $M$ has zero entries at permitted source positions and negative infinity at forbidden future positions; after softmax those forbidden weights are zero. Several heads are concatenated and linearly projected. Residual connections add an update to the current representation. A multilayer perceptron, or MLP, applies positionwise nonlinear computation. Normalization and positional information also affect actual transformer architectures.

A weighted average is not a full explanation. If a query assigns weights $(3/4,1/4)$ to scalar values $(4,0)$, its head output is $3$. Changing the first value to $0$ changes the output to $0$ even if the attention weights remain unchanged. The weights say where values are mixed; the value vectors and subsequent readout determine what information the mixture carries.

This forward-pass vocabulary is needed for Mixing Mechanisms, circuit tracing, and parameter decomposition. Their empirical claims require more than recognizing the attention formula.

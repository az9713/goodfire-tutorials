Can changing a component test an explanation?

A hidden activation may correlate with an answer without being the computation that produces it. Mechanistic interpretation becomes stronger when an explanation makes a prediction about a controlled intervention. The intervention still needs a precise target, a comparison, and a scope.

A computational graph is a directed acyclic graph of deterministic operations for a forward pass. Each node is a function of its parents. Replacing a node's computed value by a specified value while leaving the other operations intact is an intervention on that node. It is an experimental modification of this graph, not a naturally occurring input change.

Clean, corrupted, and patched runs

Let $x_c$ be a clean input and $x_r$ a corrupted comparison input. Choose a scalar score $s(f(x))$, such as a target-minus-competitor logit difference. Let $s_c$ and $s_r$ denote the corresponding scores. At a chosen location, record the clean activation $h_c$. In the corrupted run, replace that location's activation by $h_c$ and continue the forward pass, producing score $s_p$.

When $s_c\neq s_r$, a commonly useful normalized restoration score is

$$R=\frac{s_p-s_r}{s_c-s_r}.$$

It equals zero when the patch changes nothing and one when it restores the clean score. It is not a probability: overshoot and reversed effects can place it outside $[0,1]$. When the clean-corrupted difference is zero or very small, this normalization is undefined or unstable. Report raw scores and the denominator as well.

A scored intervention. Suppose $s_c=4$, $s_r=-2$, and $s_p=1$. The clean-corrupted difference is $6$ and the patch recovers $3$, so $R=1/2$. This is evidence about this patch, these inputs, and this score. It does not identify every computation supporting the answer.

Necessity, sufficiency, and redundancy

For a fixed task and intervention family, a necessity-style test removes a candidate component and measures loss of performance. A sufficiency-style test asks whether retaining or restoring a candidate set produces the relevant behavior under specified conditions. These are conditional experimental questions; they are not universal labels attached to a neuron.

Consider binary input $x\in\{0,1\}$, two identical hidden signals $h_1=x$, $h_2=x$, and output $y=\max(h_1,h_2)$. At $x=1$, removing either signal alone leaves $y=1$, whereas removing both yields $0$. A null single-node ablation is compatible with redundancy. Conversely, removing an indispensable routing node can destroy many behaviors without showing that it specifically represents the concept of interest.

Rescue the inference by testing sets of components, using conditional interventions, and checking multiple task variants. Even then, make the conclusion relative to the experimental graph. An ablation can create activations that the unmodified model never encounters.

Why intervention controls matter

Zero ablation sets an activation to zero. Mean ablation replaces it by an estimated reference mean. Resampling ablation substitutes an activation from another example. None is automatically the correct counterfactual. Zero may be far from the training distribution; a global mean can remove context; a resampled activation can combine mutually inconsistent information.

A control should address the proposed alternative explanation. For a steering direction $v$, compare it with random directions normalized to the same Euclidean norm. This controls one aspect of intervention magnitude, but not every semantic or distributional difference. For patching, use comparison inputs matched on nuisance attributes while changing the intended variable. Test whether a patch also disrupts unrelated behaviors.

Separate discovery inputs from evaluation inputs. Choosing a component because it has the largest effect and reporting the same examples as confirmation overstates evidence. Replicate across fresh prompts, random seeds, or model instances when the claim warrants it. A large effect does not by itself establish a unique mechanism.

How to read the Goodfire evidence

For the geometric calculator, ask what interventions connect number geometry to computation. For circuit tracing, distinguish the original model from an approximate interpreter. For parameter decomposition, ask which intervention distributions are used to establish faithfulness. For reward-hacking probes, distinguish successful detection from a recovered causal account.

Write an experimental claim as: on a named input distribution, modifying a named component in a specified way changes a named metric by a measured amount, compared with named controls. This statement can be tested and criticized without relying on an attractive visualization.

Exercises

  2. In the redundant binary construction, tabulate the output for every combination of removing or retaining $h_1,h_2$ at $x=1$. Which result separates redundancy from global irrelevance?
  3. A random-direction control destroys performance as much as a proposed concept direction. Give two possible interpretations and a next experiment distinguishing them.

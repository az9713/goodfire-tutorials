Worked answers

  1. The inequality concerns information and unrestricted optimal prediction. Actual classifiers have finite samples, capacity limits, and regularization. A transformed representation can make relevant structure easier to learn while discarding irrelevant information.
  2. Precision is $90/(90+30)=0.75$; recall is $90/(90+10)=0.9$; F1 is $2(0.75)(0.9)/(0.75+0.9)\approx0.81818$. These values require the same entity matching rule throughout.
  3. Cross raw and SAE representations with identical classifier families, tuning budgets, training sizes, and entity-level splits. Add language-stratified and real-data tests, keeping preprocessing frozen. Report exact and partial metrics with paired uncertainty. A consistent SAE advantage across the crossed design is stronger evidence than comparing only each representation's independently selected winner.

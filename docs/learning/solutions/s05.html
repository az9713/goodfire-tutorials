Worked solutions · S05

Interpreting Language Model Parameters

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked solutions

  1. Zero residual establishes only an exact sum of weights. The matrices $A_2$ and $A_3=-A_2$ in the example cancel when retained together or removed together, yet either alone changes the output for $x=(0,1)^\top$. An attribution graph additionally omits full nonlinear transfer functions, so its edge strengths do not specify an independently executable algorithm.
  2. A uniform variable on $[a,1]$ has variance $(1-a)^2/12$. Independence and equal means give $\mathbb E(m_2-m_3)^2=(1-a)^2/6$. The largest absolute difference is $1-a$, so worst-case squared error is $(1-a)^2$. At $a=1$, both masks must be one and all errors vanish. This is why forcing all importances to one can make reconstruction trivial while destroying minimality.
  3. On a tiny mask space enumerate binary corners, sample interior points, and compare projected-gradient attacks with multiple random starts and increased step counts. Evaluate held-out inputs with the importance network frozen. Report error against allowed importance budget. A destructive allowed mask refutes robustness on that input and intervention family; it may reveal a missing important part, harmful cancellation, or an overly strict family. It does not by itself show that every semantic label is wrong. Conversely, successful finite testing is evidence within tested masks, not a certificate over a continuous high-dimensional box.

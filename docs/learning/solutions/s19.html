Paper Summary: Interpreting Language Model Parameters

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked solutions

  1. The edit changes the actual parameters and predicts a specific behavioral consequence, establishing a causal handle. It tests only one intervention and context family, leaves the rest of the algorithm unexplained, and may have off-target effects elsewhere.
  2. Since $u'-u=(1,-2)^\top$ and $v^\top h=\epsilon$, $\delta Ah=(\epsilon,-2\epsilon)^\top$ with Euclidean norm $\sqrt5|\epsilon|$. Small nonzero reader activation creates a proportionally small local activation effect; downstream nonlinear behavior need not scale proportionally.
  3. Separate emoticons, punctuation in prose, code delimiters, and matched rare character sequences. Hold frequency and surrounding tokens approximately fixed. Measure reader activation and edit-induced token probability changes. Strong effects on unrelated punctuation would challenge the narrow label even if some emoticon predictions still change.

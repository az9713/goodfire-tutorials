Worked solutions · S28

Understanding Memorization via Loss Curvature

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked solutions

  1. Dataset curvature averages example curvature. A very large contribution supported on very few examples can have a small average. The two statements use different objectives.
  2. The average is $40p$. It is below $0.5$ when $p\lt0.0125$. At the boundary it equals the threshold.
  3. Construct held-out matched sets of recitable passages, paraphrased factual questions, rare useful facts, arithmetic, and logical tasks. Sweep edit strength and compare methods at matched perplexity or common-task performance. Test extraction with multiple prompts and distinguish true forgetting from a single suppressed continuation. Report rare-knowledge losses separately.

Mapping the Latent Space of Llama 3.3 70B

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked solutions

  1. Labels summarize sampled activation contexts, while geometric neighborhoods summarize a projection. Neither establishes that changing each feature has a different downstream effect. Test matched interventions and measure separate behaviors, including cross-effects.
  2. The middle score is always 0.9. The strongest scores $w+0.4(1-w)=0.4+0.6w$. It wins when $w\gt5/6$. Equality gives a tie. A hard factuality threshold can reject it for every weight.
  3. Inspect the original feature norms and distances, rerun neighborhood analysis with unit-normalized directions, and compare multiple embeddings and distance metrics. Isolation that disappears after normalization supports a magnitude explanation; persistence supports directional distinctness, though not a specific memorization mechanism.

Worked solutions · S36

Discovering Undesired Rare Behaviors via Model Diff Amplification

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked solutions

  1. Amplification can create trajectories with much higher probability than under the actual policy and can generate artifacts. Rechecking establishes whether the failure is supported by the deployed model and estimates its natural rate on the selected context, while acknowledging selection bias in the context itself.
  2. If $p_0=p_1$, the likelihood-ratio factor is constant and $q=p_1$ for every $\alpha$. At $\alpha=0$, the formula also reduces to $q=p_1$. Both are useful implementation checks.
  3. Predefine a prompt set and budgets, use blinded judges for harm and coherence separately, and report confirmed coherent failures per model-call or token budget. Retest candidate failures with ordinary sampling. Compare to higher temperature and random prompting at matched cost; incoherent amplified text should not count as a successful behavioral discovery.

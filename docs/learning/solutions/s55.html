Announcing Open-Source SAEs for Llama 3.3 70B and Llama 3.1 8B

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked solutions

  1. Coordinates and distributions can differ across layers or models despite equal dimensions. Directions learned in one coordinate system may no longer represent the same concepts, and normalization changes can shift thresholds and feature activity.
  2. The new fraction is $1.25\bar L_0/(2K)=0.625(\bar L_0/K)$, a 37.5% relative decrease. Higher active count does not necessarily mean lower relative sparsity.
  3. Compare reconstruction, downstream replacement loss, active-count/frequency distributions, and labeled feature behavior on matched inputs against the original checkpoint. Include causal interventions and negative controls. A good reconstruction score alone cannot validate transferred semantic labels.

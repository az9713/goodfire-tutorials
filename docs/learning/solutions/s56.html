Worked solutions

  1. The model's weights and alternative representations remain. Users may elicit the same capability through prompts, other directions, or combinations. Interface restriction changes access to a control, not necessarily the underlying computation.
  2. The conditional escape fraction is $0.2\times0.15=0.03$, or 3% of harmful requests. Multiply by harmful-request prevalence only if an unconditional traffic rate is needed.
  3. Evaluate both stages on the same labeled cases, then tabulate which cases each misses. Measure the output stage specifically on input survivors and use an adaptive held-out attack set. Shared misses show correlated blind spots; low overlap at matched individual recall supports complementarity.

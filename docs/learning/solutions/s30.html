Worked solutions · S30

Belief Dynamics Reveal the Dual Nature of In-Context Learning and Activation Steering

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked solutions

  1. The logistic map is nonlinear and saturates. Equal log-odds changes have smaller probability effects near zero or one than near one half.
  2. Set $-4+1+2m=0$, giving $m=3/2$. This is a formal model prediction; an actual model could leave its valid steering regime before reaching it.
  3. Measure full response probabilities across held-out context sizes, templates, and example mixtures. Transform calibrated binary probabilities to log odds and test whether the steering slope is constant, including interaction terms. Compare held-out likelihood with a model allowing context-dependent slopes. Avoid endpoints where numerical saturation makes odds unstable.

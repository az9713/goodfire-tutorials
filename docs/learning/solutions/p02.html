Solutions

  1. At $x=2$, $(h_+,h_-)=(2,0)$ and $y=2$. Removing $h_+$ gives $0$; removing $h_-$ gives $2$; removing both gives $0$. The second neuron is inactive on this input but necessary for correct negative-input outputs in the specified construction. A local null effect is not a statement about every input.

  2. The derivative of $-z_c$ is $-\mathbf{1}\{i=c\}$. The log-sum-exp derivative is $e^{z_i}/\sum_j e^{z_j}=p_i$. For a common shift $a$, both numerator and denominator of softmax gain the factor $e^a$, which cancels. Only relative logits affect this probability vector.

  3. Keep weights $(3/4,1/4)$ and compare values $(4,0)$ with $(0,4)$. Outputs are $3$ and $1$. To explain an actual model, vary relevant input information, patch values or head outputs, and test the downstream effect with controls. Attention-weight similarity alone does not identify which content is used or how later layers process it.

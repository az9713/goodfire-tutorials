Guided Python experiments and reproducibility

Background for the Goodfire essays. Read any chapter when useful; no placement test or progress gate is required.

Solutions

  1. For negative input the positive branch is inactive and the negative branch equals the input magnitude. Removing the negative branch should eliminate this construction's output, while removing the already-zero positive branch should not change it. Recorded activations and scores are observations; claims about necessity on other inputs require further reasoning or tests.

  2. Report the seed-selection procedure, the number of attempted runs, the full relevant distribution of results, and a fresh confirmation run or set. The selected maximum is not an unbiased estimate of typical performance. A failed run can also reveal sensitivity that matters to the mechanism claim.

  3. Record the checkpoint and preprocessing, input IDs or generated examples, token position/layer/module/channel, the replacement value and its source, whether other activations remain recomputed or fixed, the output metric, controls, seeds, software, and numerical tolerance. Save the actual patched and baseline results. This lets the reader distinguish nominally similar interventions that modify different computational graphs.

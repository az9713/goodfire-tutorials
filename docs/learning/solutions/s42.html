Interpreting Evo 2: Arc Institute's Next-Generation Genomic Foundation Model

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked answers

  1. The feature may reflect a correlated input property, a downstream consequence, or a mixture of concepts. Alignment establishes predictive correspondence. A mechanistic description additionally specifies and tests how the feature participates in computation.
  2. $F1=120/(120+15+25)=120/160=0.75$. Precision is $0.8$ and recall is $60/85\approx0.7059$, illustrating that F1 combines distinct errors.
  3. Restrict analysis to coding regions, match sequence composition and organism groups, and compare annotated secondary-structure classes on held-out gene families. Test whether the feature retains discrimination after controlling for coding status. Carefully chosen activation interventions can then test a proposed model role, while biological function still requires appropriate independent validation.

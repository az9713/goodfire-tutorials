Finding the Tree of Life in Evo 2

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked solutions

  1. Averaging random regions preserves consistent genome-wide signals and cancels many local variations. It can reveal taxonomic style while hiding gene-specific function or motifs confined to a small region.
  2. For any vector $v$, $v^\top Mv=v^\top W^\top Wv=\|Wv\|_2^2\geq0$. If $Wv=0$, that difference has zero learned Euclidean distance, so this is generally a pseudometric on the original space.
  3. Hold out entire clades, then stratify evaluation by pairs with similar GC content but different ancestry and pairs with similar ancestry but differing composition. Compare against nucleotide-frequency baselines, include region-level resampling uncertainty, and report the supervised metric separately from raw geometry.

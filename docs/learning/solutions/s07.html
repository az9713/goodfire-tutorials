Training and Deploying Production Cyber Monitors on Kimi K3

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked answers

  1. The first stage can change the selected population and support a different threshold or judge configuration. Operating points and session aggregation also matter. Compare identical judges, thresholds, data, and session rules before attributing the improvement to selection alone.
  2. $q=0.02(0.98)+0.98(0.03)=0.049$. The judge sees 4.9% of turns. Recall is $0.98(0.96)=0.9408$, or 94.08%. Ignoring probe cost, the call reduction is $1/0.049\approx20.41$.
  3. Use a harmless instrumented tool simulator and record action proposal, score availability, judge verdict, and execution timestamps. Assert that flagged actions never execute before a verdict, including cancellation, cache reuse, replica routing, and concurrent requests. Separately measure missed harmful proposals and benign interruptions; ordering correctness does not prove classifier accuracy.

Better biosecurity monitors for AI agents via protein embeddings

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked answers

  1. It removes task wording as the main distinguishing feature. A monitor must use the changed sequence or information correlated with it. It still might exploit length, formatting, or family labels, so matched wording is a control rather than proof of biological understanding.
  2. The union bound is $50(0.0002)=0.01$. Under independence the value is $1-0.9998^{50}\approx0.009951$, about 0.9951%. Dependence can change the exact value while preserving the bound.
  3. Use an already approved, non-actionable benchmark with labels and sequence-family metadata. Split by parent and family before fitting any preprocessing, compare matched length distributions, and report parent-level recall at a fixed parent-level FPR. Audit annotation provenance and uncertainty with qualified reviewers. This assesses classification robustness without performing biological design or establishing biological activity.

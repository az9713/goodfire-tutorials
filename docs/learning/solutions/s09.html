Models know when they’re reward hacking — and we can catch them at scale

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked answers

  1. The prefix may encode task difficulty, explicit vocabulary, or an upstream common cause. Prediction establishes an association with future behavior. A mechanistic account needs interventions that distinguish candidate computational pathways while preserving relevant task conditions.
  2. $\Sigma^{-1}=\operatorname{diag}(1/4,1/9)$, hence $\Sigma^{-1}v=(1/2,1/3)$. The raw direction's coordinate ratio is $2/3$, whereas the likelihood direction's is $3/2$; covariance reverses their relative weighting.
  3. Construct held-out contrasts: harmless discussion of cheating, actual task shortcuts without cheating vocabulary, difficult legitimate attempts, and authorized test manipulation. Split by environment and template. Report each group's errors and test temporally before shortcut execution. A useful detector should separate behavior from mere topic, though these controls still do not constitute a complete causal explanation.

Worked solutions · S49

How to build fast, efficient monitors for AI models using probes

These answers are available from the start. Work the exercises before reading them if you want an independent self-check.

Worked answers

  1. A command's permissibility can change when the user authorizes it. Syntax alone cannot encode that relation. The input and labels must include the governing policy and relevant approval evidence.
  2. The threshold is $4/(4+16)=0.2$. Flagging at lower scores spends more on false positives than the stated costs justify, assuming calibration and the simplified two-action model hold.
  3. Split by task family, scenario template, and repository before generating train/test variants. Include paired allowed/prohibited actions with identical command text but different authorization. Freeze layer and threshold on development data, then evaluate once on a sealed test with independent label adjudication. Report recall at fixed FPR and session-level interruptions, including long-context cases.

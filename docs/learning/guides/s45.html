Interpret an activation, then intervene without discarding its residual

The September 25, 2024 research preview combines a Llama-3-8B-Instruct sparse autoencoder with feature labels, gradient-based intervention suggestions, and feature steering. The downloaded page records that its demo interface and API were deprecated in February 2026. The method remains instructive: a sparse reconstruction is an approximation, so a careful intervention preserves the part it does not explain. Optional preparation: matrix operations and backpropagation.

Sparse does not mean a narrow bottleneck

For residual activation $x\in\mathbb R^d$, define feature vector $h=\operatorname{ReLU}(W_{\rm enc}x+b_{\rm enc})\in\mathbb R^K$ and reconstruction $\hat x=W_{\rm dec}h+b_{\rm dec}$. Here $K$ is typically larger than $d$, despite conventional autoencoders often using narrow latent spaces. The representation is constrained by sparsity of active coordinates, not by requiring fewer possible coordinates. The source reads the residual stream at layer 19.

A reconstruction-plus-sparsity objective is $L=\|x-\hat x\|_2^2+\beta\|h\|_1$, where $\beta\gt0$ sets a tradeoff. Increasing sparsity pressure can make features easier to inspect while discarding useful information. Decoder norms require attention: arbitrary rescaling of encoder outputs and decoder columns can change the L1 penalty without changing reconstruction unless training constrains that freedom.

Preserve unexplained information

Define reconstruction residual $\epsilon=x-\hat x$. Editing $h$ to $h'$ gives $x'=W_{\rm dec}h'+b_{\rm dec}+\epsilon=x+W_{\rm dec}(h'-h)$. Only the decoded feature difference is injected. Replacing $x$ by the entire SAE reconstruction would also delete $\epsilon$, mixing a feature intervention with an uncontrolled reconstruction intervention.

The source suggests candidate features using gradients of the chosen token's logit minus mean logit. If $z_j$ denotes vocabulary logit $j$, chosen token $a$, and vocabulary size $V$, its score is $G=z_a-V^{-1}\sum_jz_j$. Subtracting the mean removes a common-logit shift, which cannot change probabilities. Summing feature gradients across token positions supplies intervention candidates, but a local gradient is a prediction about a small change, not a guarantee about a large edit.

Original numerical example: what residual preservation buys

Take $x=(3,2)^\top$, reconstruction $\hat x=(3,0)^\top$, and feature direction $d_1=(1,0)^\top$ with activation three. The unexplained residual is $(0,2)^\top$. Reducing the feature to one yields edited activation $(1,2)^\top$ with residual preservation, versus $(1,0)^\top$ if the reconstruction replaces the original. The latter intervention accidentally removes the entire second coordinate.

Suppose an untouched task depends on that second coordinate. Its degradation would be falsely attributed to feature removal if the residual were discarded. Conversely, preserving the residual does not guarantee semantic selectivity: the chosen decoder direction itself might affect several downstream tasks.

The source's displayed “fidelity” ratio is $R=(\ell_{\rm SAE}-\ell_0)/(\ell_{\rm ablated}-\ell_0)$, using next-token log losses for SAE replacement, original activations, and ablation. With invented losses 2.2, 2.0, and 4.0, respectively, $R=0.1$. Under this displayed convention zero means perfect recovery and one means no improvement over ablation. A commonly used recovery fraction is $1-R$, here 0.9. State the formula before comparing numbers called fidelity; the name alone does not determine orientation.

What the preview supports

The source reports that chat-domain activations yielded more useful features for its chat use case than other considered data. This is evidence that activation coverage matters, not that one dataset is universally best. Strongly activating examples receive automated labels; those labels can miss weaker activation contexts and must be evaluated separately from reconstruction.

The article observes repeated “echo” features and asymmetry between promoting and suppressing behavior. Strengthening one feature can work while suppressing one of several related features fails. It proposes cross-layer representations and self-repair as possible explanations. These remain hypotheses: redundancy, incomplete labels, or an off-manifold negative edit could also matter.

Neither low average active-feature count nor good reconstruction establishes monosemanticity. Nor does a successful style intervention establish a complete causal explanation. Strong tests pair held-out labels, residual-preserving ablations, finite-difference checks of gradient predictions, and comparisons with prompt-only and ordinary steering-vector controls.

Exercises

  1. Concept. Why is preserving the residual necessary for a clean feature edit but insufficient for semantic selectivity?
  2. Math. If every logit increases by the same differentiable scalar $c$, show that $G$ and softmax probabilities stay unchanged.
  3. Experiment. Design a finite-difference test of a suggested feature gradient and explain what a disagreement means.

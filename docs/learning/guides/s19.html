From readable features to editable machinery

The May 5, 2026 publisher summary asks how we could understand the computations that produce an activation, rather than merely label that activation. Its answer is adVersarial Parameter Decomposition (VPD): decompose original weight matrices into simple parts, identify which parts matter on each input, and stress-test that claim by perturbing parts declared unimportant. Read this as an accessible summary of the full parameter paper, not an additional independent experiment. Optional preparation: rank and outer products and attention.

What makes a part an explanation?

Let $W\in\mathbb R^{a\times b}$ be a network matrix and $A_c=u_cv_c^\top$ a rank-one subcomponent, with $u_c\in\mathbb R^a$ and $v_c\in\mathbb R^b$. On input activation $h$, it computes $A_ch=u_c(v_c^\top h)$: read a scalar along one input direction and write it along one output direction. This is a computational operation, whereas an SAE feature is a coordinate in a learned description of activations. An SAE can help describe what is represented without explaining the original matrix operation that produced it.

The summary lists four desiderata: parts sum to the original parameters; each is simple; few matter on a given input; and allowed changes to unimportant parts preserve behavior. The full paper ensures an exact sum using residual matrices. Thus “sum exactly” does not mean the rank-one terms alone perfectly reconstruct every weight. The residual's size and ablatability must be checked.

A learned causal-importance predictor assigns $g_c(x)\in[0,1]$. Masks $m_c\in[g_c(x),1]$ determine how much of each part remains. If $g_c=0$, the method permits arbitrary partial removal; if $g_c=1$, the part must remain. Searching adversarially for destructive masks makes the test stronger than deleting all nominally unimportant terms together. It still does not exhaust the continuous mask space in a real model.

Original numerical example: editing a reader-writer part

Suppose an invented two-dimensional model contains $u=(0,2)^\top$ and $v=(1,0)^\top$. Then $A=uv^\top=\left(\begin{smallmatrix}0&0\\2&0\end{smallmatrix}\right)$ and, for $h=(3,4)^\top$, $Ah=(0,6)^\top$. Replacing the writer by $u'=(1,0)^\top$ yields $A'h=(3,0)^\top$. The reader still detects the first coordinate, but writes different downstream content. The edit is $\delta A=(u'-u)v^\top$ and has rank at most one.

For another input $h_0=(0,5)^\top$, both old and new parts output zero. This creates a precise condition for locality: the edit vanishes whenever $v^\top h_0=0$. Real data need not satisfy that orthogonality. If the reader responds to several concepts, changing the writer changes all of them. Low rank describes the geometry of the edit, not its semantic precision.

Three evidence classes in the summary

The source decomposes a 67M-parameter language model's 24 matrices into approximately 10,000 subcomponents. Its first evidence class is interpretability of parts and attention interactions, including previous-token and syntax-boundary routing across multiple heads. A human head-level partition need not match a functional mechanism's boundary.

The second is direct editing: a subcomponent associated with emoticon eyes is changed to write toward the unembedding direction of “o,” shifting predicted emoticons toward shocked faces. The edit links a discovered parameter part to behavior without retraining. That is a valuable causal demonstration, but does not imply an arbitrary fact or personality can be edited equally cleanly.

The third is local attribution graphs, including the prediction of “her” in the princess example. These summarize influence between retained parts. They are not executable algorithm descriptions: edge strengths omit full nonlinear transfer functions. The full paper also reports substantial failures under stronger adversarial masking, which the concise summary does not develop. Its optimistic language about confidence in “real computational structure” should therefore be read alongside those quantitative limits.

Alternative explanations include residual dependence, incomplete importance estimates, and labels that reflect superficial contexts rather than the operation's full role. Independent ablation, held-out prompts, edit locality, and stronger mask searches provide more discriminating tests than browsing a few coherent examples. For a scaled illustration, use the offline labs; the arithmetic above is not a reproduction of the language-model decomposition.

Exercises

  1. Concept. Why is changing an emoticon writer stronger evidence than a feature label, yet weaker than complete reverse engineering?
  2. Math. For the worked edit, compute $\delta Ah$ at $h=(\epsilon,5)^\top$ and its norm.
  3. Critique. Specify a held-out test of the claim that a reader detects emoticon eyes rather than punctuation generally.

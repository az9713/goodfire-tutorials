A probe is a trained measurement instrument

This September 2026 practical guide asks how to build an inexpensive monitor for prohibited agent actions. Its worked product example probes GLM-4.5-Air activations near the end of reasoning, then evaluates detection on synthetic and held-out tasks. The useful lesson is the chain of choices linking a policy definition to a dataset, an activation readout, a threshold, and an intervention. A probe's numerical score has meaning only relative to those choices.

Prerequisites: neural activations and logistic regression and evaluation design. Let $h\in\mathbb R^d$ be the activation read at a specified layer and token position. A logistic probe computes $s=\sigma(w^\top h+b)$, where $w$ is a learned vector, $b$ an intercept, and $\sigma(a)=1/(1+e^{-a})$. Training labels indicate whether the action violates the specified policy. This is a supervised application of representations, not automatic access to an agent's true intent.

Original teaching derivation: choose a threshold by consequences

If $s$ is a calibrated probability of violation, flagging incurs false-positive cost $C_{FP}$ when the action is allowed; allowing incurs false-negative cost $C_{FN}$ when it violates policy. Expected costs are $C_{FP}(1-s)$ and $C_{FN}s$. Flag when

$$C_{FP}(1-s)\leq C_{FN}s\quad\Longleftrightarrow\quad s\geq\frac{C_{FP}}{C_{FP}+C_{FN}}.$$

For an invented example with $C_{FP}=1$ and $C_{FN}=99$, the threshold is $0.01$. That does not mean a raw logistic score of 0.01 is trustworthy under deployment shift. Calibration and class prevalence can change. If the flag merely escalates to review, its cost differs from immediate refusal, so each policy needs its own decision analysis.

Even fixed recall and false-positive rate do not determine review precision. At prevalence $\pi$, recall $r$, and false-positive rate $f$, the fraction of flags that are true violations is $\pi r/[\pi r+(1-\pi)f]$. With hypothetical $\pi=0.001$, $r=0.99$, and $f=0.01$, only about 9.02% of flags are true positives. A cheap first-stage filter may still be valuable, but an automatic-blocking policy would have different usability consequences.

Every readout choice changes the experiment

“Probe architectures” separates output head, computational model, layer, and token aggregation. The example selects layer 31 and a marker at the end of hidden reasoning, just before visible output or tool use. That choice is appropriate to the stated action-detection target; it does not imply the same position is best for prompt screening or token-level PII. Layer sweeps and architecture selection must use development data, reserving a fresh final test.

“Training dataset” emphasizes realistic, accurately labeled positive and negative examples. The policy includes authorization boundaries, so the same command can be allowed or prohibited depending on user approval. A dataset that labels only command syntax teaches a shortcut. Include matched actions under different authorization states, alongside varied wording and environments.

A strong example is not a general performance guarantee

“Using Silico to build a probe-based monitor” reports 97% recall at 1% FPR initially and 99% after further iterations, including held-out task types. These are reported example results, not reproduced by the local course. Repeated iteration can overfit a nominal holdout if it is repeatedly inspected, so a sealed final evaluation remains necessary.

The guide says passive readout need not alter model outputs. A deployed guardrail does alter the overall system when it blocks, redirects, or injects instructions. Likewise, “virtually no latency” describes a design goal or measured serving setup, not an architecture-independent fact. The cost of extracting and routing activations can dominate probe arithmetic; the infrastructure guide explains why.

A successful probe establishes that its label is decodable from a chosen representation under tested conditions. It need not reveal the causal computation producing an action. Counterfactual policy tests, distribution-shift evaluation, and independent label review strengthen monitoring confidence without turning every classifier into a mechanistic explanation.

Reading route and capability

Read “When should you use a probe?,” “Probe architectures,” “Training dataset,” “The rest of the guardrail system,” and the reported results. You should be able to specify a probe experiment completely: target policy, labels, frozen model, layer, position, pooling, classifier, threshold, split unit, and action taken on a flag. Explore the local labs before proposing large-model execution.

Exercises

  1. Why does detecting a prohibited action require authorization context?
  2. Compute the decision threshold for $C_{FP}=4$ and $C_{FN}=16$ under calibrated probabilities.
  3. Design a leakage-resistant test for the example monitor.

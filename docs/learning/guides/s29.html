What a sparse objective forgets about time

Language arrives sequentially, yet a standard SAE reconstructs each activation largely as an isolated sample. “Priors in Time” asks what temporal assumptions this objective encodes and proposes Temporal Feature Analysis: separate a context-related component from novel residual information rather than force both into the same sparse code.

Preparation: projections, encoders and attention, priors and stationarity, sparse coding.

An objective is also a statistical assumption

Let $x_t\in\mathbb R^d$ be an activation at token position $t$, $z_t\in\mathbb R^m$ its code, and $D$ a decoder. Consider $\sum_t[\|x_t-Dz_t\|_2^2/(2\sigma^2)+\lambda\|z_t\|_1]$. A Gaussian observation model $x_t\mid z_t\sim\mathcal N(Dz_t,\sigma^2I)$ and independent Laplace priors give the same expression as a negative log posterior, up to constants:

$$P(z_{1:T})\propto\exp\left(-\lambda\sum_t\|z_t\|_1\right)=\prod_t\exp(-\lambda\|z_t\|_1).$$

The factorization is the consequential step: the prior supplies no temporal coupling. It does not imply the resulting codes on correlated data will be statistically independent. An encoder applied to correlated inputs can output correlated codes. The critique concerns a missing inductive bias in the objective's generative interpretation, not an impossibility of observing temporal structure in an SAE.

Stationarity means statistical properties remain invariant under time shifts. Independence and identical distribution are stronger assumptions than stationarity. The paper measures changing dimensionality and autocorrelation across sequence position and compares with stationary surrogate signals. These observations motivate time-aware structure, while the precise measurements depend on activation preprocessing and dimensionality estimators.

Predictable context and sparse novelty

Temporal Feature Analysis writes $x_t=x_{p,t}+x_{n,t}$, with both parts decoded through a dictionary. The predictive code is obtained using an attention-like relation between the current representation and preceding representations. A sparse encoder then explains the residual. The training objective penalizes sparsity of the novel component rather than demanding the total representation remain equally sparse at every position.

The current activation serves as a query in this construction. “Predictable” therefore means explainable using context-related directions, not necessarily a forecast computed before observing the current token. Confusing those meanings would overstate the method's predictive claim. The paper also acknowledges that assuming independent residuals is still an assumption; novelty can itself have temporal correlations.

The empirical analysis uses garden-path sentences, stories, and dialogues to test whether predictive codes track structure such as event boundaries and contextual trajectories. Reconstruction metrics provide sanity checks rather than the sole criterion. A decomposition that preserves average signal while destroying temporal relations would miss the point of the method.

Original worked example: a carried topic and a new event

Let $u,v$ be orthonormal vectors. Suppose recent context spans $u$ and the current activation is $x_t=3u+2v$. Orthogonal projection gives $x_{p,t}=uu^\top x_t=3u$ and residual $x_{n,t}=2v$. Norm squared decomposes as $13=9+4$ because the cross term is zero. This exact projection is a teaching illustration, not the learned attention mechanism or a reproduction of its results.

If a total-code TopK encoder allows only one active scalar coordinate, it must drop either carried context or novelty in this two-axis basis. A model that reuses a context channel and sparsifies only the residual can preserve both. This shows a possible advantage of separating roles. It does not prove that every context projection is semantically correct: $u$ could track position or punctuation rather than topic.

At the next time step, $x_{t+1}=3u-2v$ has the same norm but a changed novel component. Aggregate norm and reconstruction error can conceal this reversal. Evaluating temporal structure requires inspecting how the components change, not just how much energy they contain.

Evidence and limitations

The paper combines observed nonstationarity, a Bayesian account of SAE priors, and experiments with a new decomposition. These are different evidence classes. The objective factorization is mathematical; meaningful event structure is empirical; a claim that these components are the network's unique computational units would require additional causal and identifiability work.

Theoretical support-switching claims depend on assumptions about sparsity, geometry, and reconstruction error. This companion does not promote them to an unrestricted theorem that SAEs always destroy local geometry. Architecture changes also add capacity and context access, so matched-budget baselines matter. A useful control shuffles temporal order while preserving marginal activations: it tests whether benefits depend on real sequential structure.

Exercises

  1. Conceptual: Does a factorized prior imply encoded observations must be independent? Explain.
  2. Mathematical: With orthonormal $u,v,w$, context spanning $u,v$, and $x=2u-v+4w$, find the projection and residual norms.
  3. Critical experiment: How would you test whether predictive codes identify event boundaries rather than sentence punctuation?

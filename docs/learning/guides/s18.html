A steering path should respect the representation

Why can a straight activation edit produce incoherent behavior even when its endpoints are valid? The source uses weekday questions in Llama 3.1 8B to compare straight-line steering with a path following the observed representation manifold. It also asks whether the geometry of behavior can predict the geometry of useful interventions.

Preparation: distances and maps, interventions, probability distributions, curves and tangent spaces. See the geometry agenda for motivation.

Two spaces and a connecting computation

An activation $h\in\mathbb R^d$ belongs to representation space. The rest of the network maps it to an output-token distribution $p=F(h)$, belonging to the probability simplex: $p_i\geq0$ and $\sum_i p_i=1$. These spaces have different metrics. The source studies behavior using Hellinger distance,

$$H(p,q)=\frac{1}{\sqrt2}\left(\sum_i(\sqrt{p_i}-\sqrt{q_i})^2\right)^{1/2}.$$

Taking square roots maps probability vectors to the positive part of a unit sphere. This makes probabilistic differences geometrically comparable without treating raw logit distance as behavior distance. Nearby weekday answers in the source have related distributions rather than merely different top tokens.

A representation curve $\gamma(s)$ and a behavior curve $\beta(s)$ correspond when $F(\gamma(s))$ follows $\beta(s)$, perhaps with a changed parameterization. Similar-looking plots do not establish this relation: causal interventions along $\gamma$ supply the decisive additional test.

Why the chord leaves the valid set

For a smooth curve, the tangent is $\gamma'(s)$ and a local edit $h+\epsilon\gamma'(s)$ approximates motion along the curve to first order. Taylor expansion gives $\gamma(s+\epsilon)=\gamma(s)+\epsilon\gamma'(s)+\epsilon^2\gamma''(s)/2+O(\epsilon^3)$. The curvature term is exactly what a straight tangent edit neglects. A small edit can be adequate; a long edit accumulates geometric error.

The source's weekday case exhibits circular structure in both hidden activations and output distributions. Following the hidden curve moves probability through neighboring weekdays. Straight paths can move into states producing off-target tokens. This is a case-specific observation; curved representations do not imply that every linear intervention fails or that every fitted curve is safe.

Original worked example: the circle's missing center

Let valid activations be $\gamma(\theta)=(\cos\theta,\sin\theta)$. Choose endpoints $(1,0)$ and $(-1,0)$. Their linear interpolation is $h(t)=(1-2t,0)$, for $t\in[0,1]$. At $t=1/2$, it reaches $(0,0)$, distance one from every valid point. The upper semicircle interpolation remains norm one throughout. These are exact teaching calculations, not measured Llama activations.

Define an illustrative readout $F$ that uses angle to choose a weekday but emits an “unknown” token whenever $\|h\|_2\lt1/2$. The chord yields unknown outputs for $1/4\lt t\lt3/4$, while the semicircle never does. This deliberately specified decoder demonstrates a mechanism for the source's concern: valid endpoints constrain the decoder at those endpoints but say nothing about the interior chord.

The Hellinger distance between two different deterministic weekday distributions is one. Between $p=(1,0)$ and $q=(1/2,1/2)$, it is $\sqrt{1-1/\sqrt2}$. A smooth output path therefore requires intermediate uncertainty or mixing; top-token labels alone can conceal its continuity.

How to assess the reported alignment

The source compares a representation-derived path with interventions optimized to follow a behavior-derived path and reports that they align in activation space. This reverse construction is stronger than choosing a pretty activation projection. However, inverse control is underdetermined: many activation changes can yield similar token probabilities. Regularization, fitted dimension, held-out prompts, and the size of the controlled output vocabulary affect the conclusion.

Fair comparisons should match edit strength or downstream behavioral change and preserve unrelated task information. A global manifold fitted across contexts could entangle weekday identity with wording. An edit that reliably outputs Tuesday may still destroy other information. The source points to broader tasks in its linked paper; this companion's verified evidence is the downloaded weekday explainer, not those additional experiments.

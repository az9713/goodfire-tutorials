Make latent editing human-scale

An image can activate hundreds of fine-grained features, too many for an intuitive editing interface. “Painting with concepts” combines a sparse autoencoder (SAE) with non-negative matrix factorization (NMF) to bundle those features into image-specific factors. The resulting canvas can move a region, alter its contents, or combine an action with an object. Its important distinction is between model-wide learned features and per-image factors. Optional preparation: matrix factorization and activation-space interpretation.

Features are global; factors depend on this image

The source interprets SDXL-Turbo block down.2.1, where an image has 16 by 16 activation patches. A BatchTopK SAE maps each patch vector to a sparse nonnegative feature vector. BatchTopK allocates a batch-wide sparsity budget, so different patches can have different active-feature counts; it does not require exactly the same count in every patch.

Let $Z\in\mathbb R_{\ge0}^{256\times K}$ collect feature strengths, with $K$ the dictionary size. NMF finds nonnegative matrices $S\in\mathbb R_{\ge0}^{256\times r}$ and $B\in\mathbb R_{\ge0}^{r\times K}$ such that $Z\approx SB$. Here $r$ is the chosen factor count, $S$ gives spatial factor strengths, and row $B_j$ gives factor $j$'s blend of SAE features. A spatial edit changes $S$; a semantic blend edit changes $B$.

The SAE is trained across many images and defines a fixed feature dictionary. NMF is fitted for a particular image, so factor number two does not have a stable meaning across images. A “cat head” factor may combine eyes, fur, close-up composition, and style even when no single SAE feature encodes the entire head.

Original worked canvas

Consider four patches and three features, with invented factors

$$S=\begin{pmatrix}1&0\\0.5&0\\0&1\\0&0.5\end{pmatrix},\qquad B=\begin{pmatrix}2&1&0\\0&1&3\end{pmatrix}.$$

The feature matrix is $SB=\left(\begin{smallmatrix}2&1&0\\1&0.5&0\\0&1&3\\0&0.5&1.5\end{smallmatrix}\right)$. Moving factor one from patch one to patch three means setting $S_{11}$ to zero and $S_{31}$ to one. Patch one loses $(2,1,0)$, while patch three becomes $(2,2,3)$. Because feature two belongs to both factors, moving a semantic unit changes shared feature content rather than a disjoint object slot.

NMF also has a scale ambiguity: for a positive diagonal matrix $C$, $(SC)(C^{-1}B)=SB$. An interface needs a normalization convention before slider values can be compared between factors. A doubled spatial coefficient with a halved basis row produces the same feature matrix. Apparent numeric “concept strength” is partly a coordinate choice.

From factors back into generation

Let $D\in\mathbb R^{d\times K}$ be the SAE decoder, $h_p$ the original activation at patch $p$, and $z_p$ its encoded feature vector. A residual-preserving edit takes $h'_p=h_p+D(z'_p-z_p)$, retaining reconstruction error while changing selected decoded features. This formula describes a common SAE intervention principle; the source's interface manipulates factor and feature tensors and inserts the edited activations into generation.

Spatial movement in a latent grid need not translate into rigid movement in pixels. Later attention and denoising operations interpret the injected state in context. The source's action features illustrate this: a distress action applied to different animals adapts to their anatomy rather than adding identical human hands. Such examples support contextual composition, not a universal causal grammar of scenes.

Evidence, labels, and limits

The source reports an SAE with 10,240 features, expansion factor eight, and BatchTopK $k=10$, selected from a sweep. Feature labels are generated from visualizations across random seeds. Its demonstrations show practical editing possibilities, while curated examples and subjective image quality leave systematic reliability unmeasured here.

Positional features are an especially useful counterexample to naive labeling. A feature active at borders can produce an image-based visualization whose semantic label is misleading. The source notes this explicitly and adjusts NMF fitting to prevent spatial features dominating human-facing factors. An interface's concepts therefore combine unsupervised structure with engineering choices about what should be displayed.

Factor count changes the abstraction level; NMF can split an object or merge distinct objects. Feature interactions, prompt conflicts, and reconstruction errors can cause collateral changes. The public interface restricts prompts largely to style because broader prompt/canvas conflicts were confusing. Proposed extension to scientific design is a research analogy, not evidence of validated molecule or genome editing.

Exercises

  1. Concept. Why is an image-specific “dog” factor different from a global SAE feature?
  2. Math. Double column one of $S$ and halve row one of $B$. Show the reconstructed matrix is unchanged.
  3. Experiment. Design a test of whether a factor move preserves the object's identity while changing only location.

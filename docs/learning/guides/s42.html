Read biological patterns from a model that speaks nucleotides

This February 2025 overview describes sparse-autoencoder analysis of Evo 2, a genomic foundation model. The problem differs from interpreting ordinary text: model inputs are DNA, while the concepts of interest span RNA, proteins, and organism biology. The authors ask whether sparse features align with known biological annotations and whether they offer handles for future controlled generation. The page includes a March 2026 publication update; its core technical account remains the earlier overview.

Prerequisites: autoencoders and sparse representations, precision and recall, and representation geometry. For activation $x\in\mathbb R^d$, an SAE computes sparse code $f=\sigma(W_ex+b_e)$ and reconstruction $\hat x=W_df+b_d$. A feature is one coordinate of $f$ together with its decoder direction. A feature's biological name is an interpretation supported by alignment evidence, not a property guaranteed by reconstruction loss.

Original teaching case: BatchTopK allocates unequal capacity

Ordinary token-wise TopK retains $k$ code entries for every token. BatchTopK retains $kB$ entries across a batch of $B$ tokens, allowing different tokens to use different numbers of features. For an original example, let $B=2$, $k=1$, and the nonnegative encoder scores be

$$F=\begin{pmatrix}9&8&0\\7&1&0\end{pmatrix}.$$

Token-wise TopK retains 9 in the first row and 7 in the second. BatchTopK retains 9 and 8, both in the first row. Both keep two entries in total, but the second token receives no active code under BatchTopK. This can improve reconstruction allocation when tokens differ in complexity. It also means a token's retained code depends on the competing scores in its batch during this operation.

The source reports improved training loss and crisp-looking features, not a theorem that variable capacity gives more truthful biological concepts. Reconstruction should be checked alongside feature frequency, dead features, biological alignment, and intervention effects. Batch composition and inference-time thresholding need explicit treatment in a reproducible implementation.

For annotation validation, let true positives, false positives, and false negatives be $TP,FP,FN$. The ordinary F1 score is $2TP/(2TP+FP+FN)$. If an invented feature overlaps 80 annotated positions, fires incorrectly at 20, and misses 40, F1 is $160/(160+20+40)=8/11\approx0.7273$. Domain-level matching can use a different unit than nucleotide-level counting, so the paper's domain-F1 definition must be respected rather than silently replaced with this teaching illustration.

Alignment is stronger than a suggestive plot, weaker than biology

“Training an Evo 2 interpreter model” describes BatchTopK SAEs trained on layer 26 and comparison with known biological concepts using domain-F1. “Why layer 26?” says the layer was selected after initial inspection because its features appeared biologically interesting. This is a practical exploration strategy, but selection makes a held-out, systematic alignment analysis especially important.

“Deciphering Evo 2's latent space” gives examples involving coding regions, secondary structure, RNA classes, and viral-derived regions. “Annotating a bacterial genome” overlays feature activations with annotations and a predicted protein structure. Such convergence supports semantic interpretation. A structure predictor is another computational model, however, so agreement between two predictions is not equivalent to independent experimental confirmation.

Correlations can arise because nearby biological properties co-occur: coding status, nucleotide composition, organism identity, and protein structure are not independent. A feature interpreted as secondary structure might partly track an upstream sequence regularity. Matched controls and held-out organisms or gene families help distinguish interpretations. Causal steering tests add a different kind of evidence, but changes in generated DNA do not by themselves validate downstream biological function.

The source explicitly describes steering as preliminary. Its broader hopes for discovery and engineering should remain goals, not completed capabilities. There is no basis here for clinical prediction, safe sequence design, or treatment advice. The self-contained takeaway is a method for proposing and auditing representation-level hypotheses.

Reading route and capability

Read “Interpreter model overview,” “Why did we switch to BatchTopK?,” “Why layer 26?,” and “Annotating a bacterial genome.” The page points to Sections 2.4 and 4.4 and Figure 4 of the underlying preprint for further detail; those references identify additional reading rather than imply that an absent paper is required for this companion. Exercises

  2. Compute F1 for $TP=60$, $FP=15$, and $FN=25$.
  3. Design a test separating coding-region detection from a proposed secondary-structure feature.

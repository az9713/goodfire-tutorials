Can coordinated interference explain adversarial errors?

The title advances a strong hypothesis. The paper's evidence is more carefully scoped: feature superposition can create adversarial vulnerability in toy models, adversarial training changes that geometry, and robust real models are easier for SAEs to reconstruct. The real-model step uses a proxy and does not directly manipulate superposition.

Preparation: Gram matrices and norm bounds, ReLU networks, causal identification, superposition. Compare the native-neuron critique by separating definitions and evidence.

Small pairwise effects can combine

Let activation $h=\sum_i a_if_i$ combine feature directions $f_i\in\mathbb R^d$. If a readout for target $j$ uses $f_j^\top h$, then

$$f_j^\top h=a_j\|f_j\|_2^2+\sum_{i\ne j}a_i\langle f_j,f_i\rangle.$$

The second term is interference. More than $d$ nonzero directions cannot all be mutually orthogonal in $\mathbb R^d$, although dependence alone does not determine whether interference causes a harmful decision. Biases and nonlinearities can suppress typical cross-talk when only a few coefficients are active. An adversary can instead coordinate changes to align many cross-terms.

The Gram matrix $G_{ij}=\langle f_i,f_j\rangle$ records this geometry. Counts of features per dimension summarize capacity use, while the actual off-diagonal pattern determines which targets can be attacked. Two representations with the same count can therefore have different robustness. The paper's antipodal regimes and robust-model comparisons motivate this qualification.

The perturbation budget limits the effect

For target $j$, let $c$ collect its cross-correlations with the perturbed coefficients and let $\delta$ be their changes. Target interference changes by $c^\top\delta$. Under $\|\delta\|_2\leq\epsilon$, Cauchy–Schwarz gives

$$|c^\top\delta|\leq\epsilon\|c\|_2.$$

If $c\ne0$, equality is achieved by $\delta=\epsilon c/\|c\|_2$ for the positive effect. Under an $\ell_\infty$ budget $|\delta_i|\leq\epsilon$, the maximum is instead $\epsilon\|c\|_1$. Thus interference can grow with the number of aligned channels, but it is not arbitrarily large under a fixed finite geometry and fixed norm budget.

This coefficient-space calculation does not automatically produce an imperceptible pixel-space attack. A real network's input-to-feature Jacobian determines which coefficient changes are reachable and at what input cost. Nonlinear gating can also change the local map.

Original worked example: many weak channels

Suppose 100 interfering channels each have correlation 0.05 with a target. Then $\|c\|_2=0.5$. With coefficient-space budget $\epsilon=0.2$, maximum target shift is $0.1$. Distributing the budget equally gives each channel $\delta_i=0.02$, and the sum is $100(0.05)(0.02)=0.1$. A single changed channel under the same $\ell_2$ budget shifts the target by only $0.01$.

This invented example illustrates coordinated amplification; it is not a source experiment or a claim about pixel perceptibility. A decision margin smaller than 0.1 could be crossed, while a larger margin would survive this particular linearized attack. Robustness depends on both interference and the margin.

Three experiments with different causal strength

The toy setup has known ground-truth input features compressed into a lower-dimensional hidden state and reconstructed through a nonlinearity. Varying feature sparsity changes learned superposition and attack vulnerability. Adversarial training changes both robustness and interference geometry. Changing sparsity also changes the data distribution, a limitation the paper discusses; the reverse intervention supplies complementary evidence.

For real ResNet models, the authors compare adversarially trained checkpoints and measure SAE reconstruction at matched sparsity. They interpret lower SAE loss as lower superposition. This proxy is not uniquely specific: differences in geometry, intrinsic dimension, activation distributions, or dictionary compatibility could also affect reconstruction. The paper cannot directly intervene on real-model superposition, so the direction “less superposition causes robustness” remains less established there.

The evidence supports superposition as a candidate causal contributor in controlled regimes. It does not show it is the only explanation for adversarial examples, nor that every interpretable native neuron is free of adversarial vulnerability. Hypotheses about native-neuron legibility and compressed feature interference must be compared using the same operational definitions.

Exercises

  1. Conceptual: Why does equal features-per-dimension fail to guarantee equal robustness?
  2. Mathematical: With $c=(0.3,-0.4)$ and $\ell_2$ budget 0.1, find the maximizing perturbation and target shift.
  3. Critical experiment: Propose a control testing whether lower SAE loss reflects something besides lower superposition.

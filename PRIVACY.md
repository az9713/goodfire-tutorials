# Public publication boundary

Only the static tutorials, generated teaching figures, local experiment code and
results, a minimal source catalog, and publication documentation are tracked.

The default-deny `.gitignore` excludes the local research archive, learner state,
diagnostic responses, agent handoffs, browser screenshots, raw source downloads,
cached publisher assets, private build records, and offline archive ZIP files.
Host-specific paths and learner-specific profile and hardware details are removed
from the public edition. Email addresses are permitted.

Public research-author names, source titles, citations, and publisher links are
retained for attribution. The repository account name and public commit identity
are intentional. Git commits use the repository account's no-reply email identity.

The verification script checks published text and links, credential patterns,
unexpected files, tracked content, and all reachable Git commit trees. The initial
publication starts from clean history; private working files are never committed.
There are no analytics, remote fonts, cookies, or learner-progress collection in
the tutorial site. External source links open only when selected by a reader.
